# Guild+

Guild+ is a client-side quality-of-life mod for the Hypixel Network that enhances the guild chat experience with cleaner Discord bridge messages, customizable formatting, and other guild-focused improvements.

The primary goal of Guild+ is to make guild chat easier to read while remaining lightweight, configurable, and compatible with existing Discord bridge bots.

## Features

### Discord Bridge

- [ ] Clean formatting for Discord bridge messages
- [ ] Custom bridge prefix (e.g. `Bridge >`)
- [ ] Hide redundant bot usernames and ranks
- [ ] Custom colors and formatting
- [ ] Highlight Discord usernames
- [ ] Bridge message indicators/icons

### Guild Chat

- [ ] Chat formatting customization
- [ ] Mention highlighting
- [ ] Keyword highlighting
- [ ] Timestamp support
- [ ] Compact guild chat mode

### Quality of Life

- [ ] Configuration GUI
- [ ] Customizable colors
- [ ] Per-feature enable/disable
- [ ] Import/export configuration
- [ ] Performance-focused implementation

## Example

### Vanilla

```
Guild > BridgeBot [Admin]: DiscordUser: Hello everyone!
```

### Guild+

```
Bridge > DiscordUser: Hello everyone!
```
